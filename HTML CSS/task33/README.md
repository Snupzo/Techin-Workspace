# CSS Variables pavyzdys

Failai:
- `index.html`
- `styles.css`
- `script.js`

## Kaip atidaryti VS Code
1. Atsisiųsk aplanką arba failus.
2. VS Code pasirink `File -> Open Folder`.
3. Atidaryk `css-variables-pavyzdys` aplanką.
4. Paleisk `index.html` naršyklėje.

## Ką šiame pavyzdyje rasi
- `:root` CSS kintamuosius
- dark/light temą
- lokalų kintamąjį komponentui
- mygtukų variantus per CSS variables
- dinaminį reikšmių keitimą per JavaScript

## Ką verta pasibandyti
- pakeisti `--color-primary`
- pridėti naują temą
- susikurti `--spacing-2xl`
- padaryti atskirą kortelės variantą su savo kintamaisiais
